# SAAD MAP — Android
مشروع أولي مستقل لتطبيق خرائط ومتابعة رحلات لهواتف Android/HONOR.

## الوظائف الموجودة
- خريطة OpenStreetMap عبر الإنترنت.
- تحديد GPS والسرعة.
- البحث عن الأماكن عبر Nominatim.
- رسم مسار قيادة تجريبي عبر OSRM.
- بدء/إنهاء الرحلة، المسافة والمدة.
- تقدير الوقود والتكلفة من معدل يحدده المستخدم.
- حفظ بلاغات الكاميرات محلياً والتنبيه عند الاقتراب منها.

## حدود النسخة
- هذه نسخة أولية وليست ملاحة معتمدة؛ لا تعتمد عليها وحدها أثناء القيادة.
- لا تحتوي قاعدة موثقة لكاميرات العراق. البلاغات يضيفها المستخدم وتظهر كغير موثقة.
- الوقود تقديري وليس قراءة من السيارة أو OBD-II.
- الخرائط والبحث والمسارات تحتاج إنترنت. الخرائط دون اتصال غير مفعلة.
- لا يوجد توجيه صوتي turn-by-turn في هذه النسخة.
- خدمات OSM/Nominatim/OSRM عامة وتخضع لسياسات الاستخدام والتوافر.

## بناء APK عبر GitHub Actions
1. أنشئ مستودعاً جديداً باسم `SAAD-MAP`.
2. ارفع محتويات هذا المجلد إلى جذر المستودع.
3. افتح تبويب Actions وانتظر `Build SAAD MAP APK`.
4. نزّل Artifact باسم `SAAD-MAP-debug-apk` من نتيجة البناء.
5. فك ضغط Artifact وثبّت `app-debug.apk` على الهاتف.

## متطلبات البناء
JDK 17، Android SDK Platform 35، AGP 8.7.3، Gradle 8.9.
الناتج Debug APK للاختبار وليس إصدار متجر موقعاً بمفتاح release.
